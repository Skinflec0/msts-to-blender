Your Train Simulator models, in Blender.

Turns MSTS and Open Rails .s shapes and .ace textures into .glb files. One Python script. Point it at a folder and wait.

Get it on GitHub Download ZIP

Run it

pip install numpy Pillow

python msts_to_glb.py                  # pick a folder in a dialog
python msts_to_glb.py path/to/folder   # convert every .s inside
python msts_to_glb.py wagon.s -o out   # one file, custom output folder

Then in Blender choose File > Import > glTF 2.0. On Windows you can drag a folder onto the script instead.

What you get

  • Meshes with normals and UVs, axes converted from MSTS to glTF
  • The full node hierarchy: bogies, wheels, doors keep their transforms
  • Textures embedded in the file, with cut-out and soft alpha detected
  • A log line for every missing or unreadable texture, and the batch keeps going

Options

-o DIRWrite the .glb files to another folder
-t DIRSearch an extra folder for textures
--lod NExport a lower level of detail; 0 is the best
--skip-existingDon't overwrite earlier output
--double-sidedShow both sides of every face
--zfight 0.002Nudge overlapping surfaces apart

Not supported yet

  • Text-format .s files: re-save them as binary first
  • DXT-compressed .ace textures: the model converts with a grey placeholder
  • Animations: only the static pose is exported
